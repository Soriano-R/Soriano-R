# Data Scientist | Machine Learning Engineer | Data Engineer

I build data pipelines, machine learning systems, and applications that turn complex data into useful, reliable software. My work spans Python, SQL, ML evaluation, backend services, and desktop applications.

## Selected projects

- [ReviewQueue.WPF](https://github.com/Soriano-R/reviewqueue-wpf) (private): .NET 10 WPF and SQL Server review-queue modernization with controlled editing, optimistic concurrency, and audit-aware persistence. The documented baseline is Milestone 5; Milestone 6 remains planned.
- [FuelWise](https://github.com/Soriano-R/fuelwise) (private): fuel-price forecasting and trip-cost estimates using EIA and AFDC data, with explicit geographic coverage limitations.
- [MacOps Copilot](https://github.com/Soriano-R/macops-copilot) (private): local-first macOS support assistant built with SwiftUI, FastAPI, retrieval, and privacy-redacted diagnostics.
- [SafeLane DQN](https://github.com/Soriano-R/safelane-dqn) (private): highway-driving reinforcement-learning simulation with a DQN agent and documented baseline comparisons.
- [Disaster Response Pipeline](https://github.com/Soriano-R/disaster-response-pipeline): NLP classification pipeline and Flask interface for categorizing disaster-related messages.
- [Recommendations with IBM](https://github.com/Soriano-R/recommendations-with-ibm): exploratory analysis, rank-based recommendations, collaborative filtering, and matrix factorization.
- [Dog Breed Classifier](https://github.com/Soriano-R/dog-breed-classifier): computer-vision classification project using convolutional networks and transfer learning.
- [Employee Dashboard](https://github.com/Soriano-R/employee-dashboard): Python-based employee performance dashboard with SQLite, charts, and team filtering.
- [North Star Bakery](https://github.com/Soriano-R/north-star-bakery): responsive web-development coursework project.

Private repositories are listed for portfolio context; their source code is not publicly accessible.
